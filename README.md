# ソフトテニス試合ノート（移転済み）

試合ノートは 2026-10-03 に「ソフトテニスIQ」アプリへ移りました。

- 今の公開版：https://omicreate.github.io/softtennis-iq/#/note
- 開発：[omicreate/softtennis-iq](https://github.com/omicreate/softtennis-iq)

このリポジトリは、旧 URL（https://omicreate.github.io/soft-tennis-note/ ）を移転先へ転送するためだけのものです。

- `index.html`：移転先へ転送します（`?src=` などの印は引き継ぎます）
- `sw.js`：ホーム画面に入れていた端末の古いキャッシュを消して、登録を解除します（試合の記録は消しません）
- `manifest.webmanifest`・`icons/`：ホーム画面に入れていた端末のために残しています

試合の記録は同じドメイン（omicreate.github.io）の端末内に保存されているので、移転先でそのまま引き継がれます。
