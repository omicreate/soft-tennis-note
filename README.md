# ソフトテニス試合ノート

スマホで使うことを前提にした、ソフトテニス専用の試合記録・分析アプリです。

## テスト利用時の説明

- 試合を外から見て、保護者・控え選手・指導者が記録する想定です
- 選手本人が試合中に入力する想定ではありません
- 入力データは端末内のブラウザに保存され、管理者へ自動送信されません
- 共有する場合はCSV出力します
- オフライン利用に備えて、試合前に電波の良い場所で一度アプリを開いてください

## 使い方

`index.html` をブラウザで開くと利用できます。

- `+` から新規試合を作成
- 種別はダブルス、シングルスから選択
- 試合形式は5ゲームマッチ、7ゲームマッチ、9ゲームマッチ、ファイナルゲームのみから選択
- 日付、時間帯、天気、気温、風、風向き、コート種別、コート状態、相手の基本布陣、区分、コートを選択式で記録
- 得点ボタンでポイントを記録
- サービスサイド、得点パターン、ミス/失点パターン、半面コート上の到達位置を中心に保存
- 余裕がある時だけ、ボールの結果、誰のプレーか、最後のショット、打球面、ラリー数、メモを追加
- `分析` タブで得点率、得点パターン、ミス/失点パターン、前半ゲーム取得、序盤失点、ダブルフォールト、レシーブミス、第1サービス開始率、平均ラリー、コース傾向を確認
- `履歴` タブで各ポイントの流れを確認
- `CSV出力` で記録データを書き出し

## スコア仕様

- 初期設定は7ゲームマッチ
- 5ゲームマッチは3ゲーム先取
- 7ゲームマッチは4ゲーム先取
- 9ゲームマッチは5ゲーム先取
- 通常ゲームは4ポイント先取、2ポイント差
- ファイナルゲームは7ポイント先取、2ポイント差
- 練習用にファイナルゲームのみの記録も可能
- ファイナルゲーム中は2ポイントごとにサービスサイドを自動で交替
- ファイナルゲーム中のチェンジサイズ確認タイミングを画面に表示
- 3、4、5ゲーム先取を新規試合作成時に選択可能

## 分析で重視している項目

- ゲーム序盤の失点
- 自ペアのダブルフォールト
- 自ペアのレシーブミス
- 自ペアの得点パターン
- ミス/失点パターン
- ネット、サイドアウト、バックアウト
- 半面コート上の到達位置
- 前半の取得ゲーム数
- 打球面別の失点
- 誰のプレーだったか
- ストローク、ボレー、スマッシュなどショット別のポイント内容

- サービス
- レシーブ
- ショット
- ストローク
- ロビング
- 失ポイント
- チェンジサイズ

補足: 審判の正式なコールは「アウト」ですが、アプリでは分析用の分類として「サイドアウト」「バックアウト」を使っています。

## ファイル構成

- `index.html`: アプリ画面
- `styles.css`: スマホ向けUI
- `app.js`: スコア進行、記録、分析、保存、CSV出力
- `manifest.webmanifest`: PWA用マニフェスト
- `sw.js`: オフラインキャッシュ用サービスワーカー
