# ソフトテニス試合ノート

スマホで使うことを前提にした、ソフトテニス専用の試合記録・分析アプリです。

公開URL: https://omicreate.github.io/soft-tennis-note/

現在の表示バージョン: `v215`

更新内容は `CHANGELOG.md` に残します。

## 利用条件

このリポジトリおよびアプリの著作権は OmiCreate に帰属します。  
許可なく、コード・画面・設計書・画像・文言の転載、再配布、改変利用、販売、第三者サービスへの組み込みを行うことを禁じます。

詳しくは `TERMS.md`、`PRIVACY.md`、`SECURITY.md` を確認してください。

## テスト利用時の説明

- 試合を外から見て、保護者・控え選手・指導者が記録する想定です
- 選手本人が試合中に入力する想定ではありません
- 入力データは端末内のブラウザに保存され、開発者・管理者・コーチの端末やサーバーへ送られません
- 共有する場合はサマリー画像を使い、詳細確認や管理用にはCSVを出力します
- 本名を使わず、学校名・Aチーム・後衛/前衛などでも記録できます
- オフライン利用に備えて、試合前に電波の良い場所で一度アプリを開いてください

## 使い方

`index.html` をブラウザで開くと利用できます。

- `メニュー` から新規試合を作成
- 新規試合や試合情報編集では、必要に応じて `入力をリセット` で初期値に戻せます
- 画面下部または `メニュー` の `バージョン情報` で、現在の版を確認
- 種別はダブルス、シングルスから選択
- 試合形式は5ゲームマッチ、7ゲームマッチ、9ゲームマッチ、ファイナルゲームのみから選択
- 日付、時間帯、開始時刻、終了時刻、天気、気温、風、コート種別、コート状態、相手の基本布陣、区分、大会名、開催地／会場、コートを記録
- 開始時刻は新規試合作成時、終了時刻は試合終了時に自動入力され、メニューの `試合情報を編集` から修正可能
- 得点ボタンでポイントを記録
- サービスサイド、得点パターン、ミス/失点パターン、半面コート上の到達位置を中心に保存
- 余裕がある時だけ、ボールの結果、誰のプレーか、最後のショット、打球面、ラリー数、メモを追加
- `分析` タブで得点率、得点パターン、ミス/失点パターン、前半ゲーム取得、序盤失点、ダブルフォールト、レシーブミス、第1サービス開始率、平均ラリー、コース傾向を確認
- `履歴` タブで各ポイントの流れを確認
- 履歴は試合日を表示し、ゲームごとに折りたたみ表示。`すべて`、`自チーム得点`、`相手得点`、`ミスだけ`、`ゲーム終盤` で絞り込み、`新しい順` / `古い順` で並び替え可能
- `サマリー画像を見る` で共有用または詳細保存用の画像を確認して保存。画像にはチーム名とプレイヤー名を含める
- `共有` でスマホの共有メニューからLINEなどへ送信
- 記録した試合は端末内の保存済み試合へ自動で残る
- `保存済み試合` で、自動保存された試合を確認・開き直し・削除
- `保存済み試合` では、保存件数とこの端末内で使っている容量の目安を確認
- `この分析を保存` で「優先度順アドバイス」を時刻・スコア付きで残し、サマリー画像にも反映
- `管理用` を開くと、詳細確認用のCSVを書き出せます
- `管理用` の `試合データを保存` で、現在の試合と保存済み試合を端末に保存できます
- `管理用` の `試合データを読み込む` で、保存した試合データを復元できます

## スコア仕様

- 初期設定は7ゲームマッチ
- 5ゲームマッチは3ゲーム先取
- 7ゲームマッチは4ゲーム先取
- 9ゲームマッチは5ゲーム先取
- 通常ゲームは4ポイント先取、2ポイント差
- ファイナルゲームは7ポイント先取、2ポイント差
- 練習用にファイナルゲームのみの記録も可能
- ファイナルゲーム中は2ポイントごとにサービスサイドを自動で交替
- ファイナルゲーム中のチェンジサイズ確認タイミングを画面に表示
- 3、4、5ゲーム先取を新規試合作成時に選択可能

## 分析で重視している項目

- ゲーム序盤の失点
- 自チームのダブルフォールト
- 自チームのレシーブミス
- 自チームの得点パターン
- ミス/失点パターン
- ネット、サイドアウト、バックアウト
- 半面コート上の到達位置
- 前半の取得ゲーム数
- 打球面別の失点
- 誰のプレーだったか
- ストローク、ボレー、スマッシュなどショット別のポイント内容

## 用語の参考

画面文言は、公益財団法人日本ソフトテニス連盟の用語ページを参考にしています。
https://www.jsta.or.jp/about_softtennis/words

- サービス
- レシーブ
- ショット
- ストローク
- ロビング
- 失ポイント
- チェンジサイズ

補足: 審判の正式なコールは「アウト」ですが、アプリでは分析用の分類として「サイドアウト」「バックアウト」を使っています。

## ファイル構成

- `index.html`: アプリ画面
- `app-config.js`: バージョン、保存キー、初期値、分析コメント設定
- `app-analysis.js`: 分析コメント生成、得点タイプ判定
- `app-storage.js`: 保存済み試合の読み書き、容量表示
- `app-rules.js`: スコア進行、ゲーム取得、ファイナルゲーム、サーバー交替判定
- `styles.css`: スマホ向けUI
- `app.js`: 画面操作、記録、分析、保存、CSV出力
- `manifest.webmanifest`: PWA用マニフェスト
- `sw.js`: オフラインキャッシュ用サービスワーカー
- `TERMS.md`: 利用条件、権利、免責
- `PRIVACY.md`: 保存データ、外部送信、削除方法
- `SECURITY.md`: セキュリティ方針、脆弱性連絡、運用方針
- `LICENSE.md`: オープンソースではないこと、All rights reservedの明記
- `CHANGELOG.md`: 更新履歴
- `docs/00-document-map.md`: ドキュメント一覧と読む順番
- `docs/security-and-compliance.md`: セキュリティ、プライバシー、権利、法令面の整理
- `docs/release-readiness-review.md`: 最終リリース時点のレビュー、分割候補、残課題
- `docs/requirements.md`: 要件定義
- `docs/basic-design.md`: 基本設計・方式設計
- `docs/detailed-design.md`: 詳細設計
- `docs/test-design.md`: テスト設計
- `docs/project-structure.md`: ローカル構成・管理ルール
- `docs/expansion-roadmap.md`: 他スポーツや別アプリへの横展開メモ
- `docs/technical-review.md`: 技術レビュー・改善バックログ
- `docs/requirements-design.md`: 既存の統合版要件・設計書
- `docs/deployment.md`: 公開・テスト環境の運用メモ

## テスト

```sh
node --check app-config.js
node --check app-analysis.js
node --check app-storage.js
node --check app-rules.js
node --check app.js
node --check sw.js
node tests/analysis-counts.test.js
node tests/match-flow.test.js
node tests/responsive-static.test.js
npm run test:e2e
```

Playwrightを使う場合は、初回のみ以下を実行します。

```sh
npm install
npx playwright install chromium
```
