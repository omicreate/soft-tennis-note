# 実機確認チェックリスト

最終更新: 2026-06-01
対象バージョン: v153

## 1. 目的

GitHub Pagesで公開したアプリが、実際のスマートフォンで問題なく使えるか確認する。
Playwrightの自動テストでは見つけにくい、ブラウザ差、共有機能、保存挙動、画面の見切れを重点的に見る。

## 2. 確認対象

最低限、以下で確認する。

| 種別 | ブラウザ | 優先度 |
| --- | --- | --- |
| iPhone | Safari | 高 |
| iPhone | Chrome | 中 |
| Android | Chrome | 高 |
| Android | Google標準ブラウザ | 中 |

## 3. 確認前の準備

- 公開URLに `?v=バージョン番号` を付けて開く
- フッターまたはメニューのバージョン表示が最新か確認する
- LINE内ブラウザで開いた場合は、標準ブラウザで開く案内も試す
- 既存データがある端末では、試合データ保存を先に行う

## 4. 基本表示

| 確認項目 | OK条件 |
| --- | --- |
| 初回表示 | 記録画面が表示される |
| バージョン | 最新バージョンが表示される |
| スコアボード | ゲーム数、ポイント数が見切れない |
| 下部タブ | 記録、分析、履歴が押しやすい |
| 横スクロール | 画面が左右にはみ出さない |

## 5. 記録操作

| 確認項目 | OK条件 |
| --- | --- |
| 新規試合 | ダブルス、シングルスを選べる |
| 試合情報 | 日付、時刻、天気、コートなどを入力できる |
| 1ポイント記録 | サービス、内容、プレイヤー、得点側を保存できる |
| 取り消し | 前のポイントに戻せる |
| 試合終了 | 勝った側が分かる |

## 6. 分析画面

| 確認項目 | OK条件 |
| --- | --- |
| 分析コメント | 記録内容に応じて表示が変わる |
| 次に見ること | 上から順に確認できる |
| 全体の傾向 | 自分たちで取った点、相手ミス、ミス失点が見える |
| 個人別+/- | 全選手が表示される |
| 文字切れ | 長い名前でも大きく崩れない |

## 7. 履歴・保存済み試合

| 確認項目 | OK条件 |
| --- | --- |
| 履歴 | 1ポイントごとに確認できる |
| ゲーム区切り | ゲームごとに見やすい |
| 保存済み試合 | 保存、開き直し、削除ができる |
| 絞り込み | 日付、種目、状態で探せる |
| 並び替え | 新しい順、古い順、名前順が使える |

## 8. 画像・共有

| 確認項目 | OK条件 |
| --- | --- |
| サマリー表示 | 画像プレビューが表示される |
| 共有用/詳細保存用 | 切り替えできる |
| 画像保存 | 端末に保存できる |
| 共有 | 対応端末では共有メニューが出る |
| 文字被り | サマリー画像内で文字が重ならない |

## 9. オフライン・保存

| 確認項目 | OK条件 |
| --- | --- |
| 再読み込み | 入力済みデータが残る |
| 機内モード | 事前に開いていれば画面が表示される |
| ブラウザ変更 | 別ブラウザではデータが引き継がれないことを理解できる |
| データ保存 | 試合データを保存できる |
| データ読込 | 保存した試合データを読み込める |

## 10. 判断基準

公開してよい条件:

- iPhone SafariとAndroid Chromeで、記録、分析、保存、サマリー画像が使える
- 文字切れやボタン見切れが、記録を妨げるレベルで発生しない
- 保存済み試合を開き直せる
- サマリー画像を保存できる

公開を止める条件:

- 得点記録ができない
- スコアが明らかに誤る
- 画面下部の主要ボタンが押せない
- 保存データが意図せず消える
- サマリー画像や試合データに、入力していない情報が混ざる
