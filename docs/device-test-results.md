## 3. 確認手順

### 3.1 表示確認

URL:

```text
https://omicreate.github.io/soft-tennis-note/?v=141
```

確認すること:

- 画面下部またはメニュー内に `v141・2026-05-28` が表示される
- スコアボードが画面幅に収まる
- 下部タブが押せる
- 横スクロールが発生しない

### 3.2 記録確認

入力例:

| 項目 | 値 |
| --- | --- |
| 種目 | ダブルス |
| 試合形式 | 7ゲーム |
| 自チーム | 実機確認 自チーム |
| 相手 | 実機確認 相手 |
| 大会名 | 実機確認 |
| コート | 第1コート |

確認すること:

- 新規試合を開始できる
- 1ポイント記録できる
- 前のポイントに戻せる
- 分析、履歴に記録内容が反映される

### 3.3 保存済み試合確認

確認すること:

- `今の試合を保存` で保存できる
- `保存済み試合` に表示される
- 日付、種目、状態で絞り込みできる
- 保存済み試合を開き直せる
- 不要な保存済み試合を削除できる

### 3.4 サマリー画像確認

確認すること:

- サマリー画像を表示できる
- 共有用、詳細保存用を切り替えられる
- 画像を保存できる
- 共有ボタンを押した時にOSの共有画面が出る、または画像保存に切り替わる
- 文字被りがない

### 3.5 オフライン確認

確認すること:

- 一度URLを開いた後、機内モードでも画面が表示される
- 入力済みの試合が再読み込み後も残る
- 試合データを保存できる
- 保存した試合データを読み込める
