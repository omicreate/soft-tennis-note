# セキュリティ・プライバシー・権利整理

最終更新: 2026-06-23
対象バージョン: v1.0.0

## 1. 現時点の公開方針

ソフトテニス試合ノートは、テストユーザーへ無料で配布する静的Webアプリとして公開する。

現時点では、正式な商用サービス、有料アプリ、AI連携サービスとしては扱わない。

## 2. GitHub公開と権利

GitHubのPublicリポジトリでは、GitHubの機能として閲覧やforkが可能になる。

一方で、このリポジトリにはMIT Licenseなどのオープンソースライセンスを付けない。GitHub上で見えることと、コードや設計を自由に再利用できることは分けて扱う。

運用:

- `package.json` は `UNLICENSED` とする
- `LICENSE.md` に All rights reserved を明記する
- `TERMS.md` に無料利用の範囲と禁止事項を明記する
- Public公開する前に、実名、学校名、個人CSV、APIキーが含まれていないか確認する

参考:

- GitHub Docs: Licensing a repository
- GitHub Docs: GitHub Terms of Service

## 3. 個人情報・プライバシー

入力される可能性がある情報:

- 選手名
- チーム名、学校名
- 大会名、会場名
- 試合メモ
- 試合日時

現時点の対策:

- 外部サーバーへ自動送信しない
- ブラウザ内保存を基本にする
- サマリー画像は端末内Canvasで生成する
- 共有は利用者の明示操作時だけ行う
- Git管理するfixtureは匿名化する
- 実運用CSVはGit管理しない

利用者へ伝えること:

- 本名を入れず、役割名や仮名でも使える
- 共有画像では `役割のみ` を選べる
- 端末データ削除やブラウザ変更で記録が見えなくなることがある
- 重要な試合はサマリー画像、CSV、引き継ぎ用データで別途保存する

## 4. セキュリティ対策

実装済み:

- Content Security Policyを設定
- 外部スクリプトを読み込まない
- HTML表示時に `escapeHtml()` を使う
- CSV出力時に `escapeCsvCell()` を使い、数式注入を避ける
- 引き継ぎ用データはアプリ識別子を確認してから読み込む
- Service Workerのキャッシュ名をバージョンごとに更新
- 個人CSVを `.gitignore` で除外
- npm依存関係の脆弱性確認を実施

最終確認:

```text
npm audit --audit-level=moderate
found 0 vulnerabilities
```

## 5. 法令・規約面の現実的な整理

この文書は法律助言ではない。個人開発のテスト公開として、現実的に守るべき線を整理する。

重要な方針:

- 個人情報を開発者側へ集めない
- SNS共有時は個人名を出しすぎない
- 無料配布でも著作権と利用条件は明記する
- オープンソースではないことを明記する
- 公式記録、審判判定、指導効果を保証しない
- AI連携を始めるまでは外部送信しない

## 6. AI機能を追加する場合の追加条件

AI機能を入れる場合は、現状とは別のリスクが発生する。

実装前に必ず決めること:

- どのデータをAIへ送るか
- 本名や学校名を送るのか、匿名化するのか
- API費用を誰が負担するか
- 保存されるログの扱い
- 利用者への同意表示
- 有料化または利用制限
- 誤った助言が出た時の免責表現

現時点ではAI機能は未搭載とし、外部AI APIへ試合データは送信しない。

## 7. リリース前チェック

公開前に確認する。

- `README.md` の公開URLとバージョンが最新
- `CHANGELOG.md` に更新内容がある
- `TEST_REPORT.md` に検証結果がある
- `TERMS.md`、`PRIVACY.md`、`SECURITY.md` がある
- `npm run test:quick` が通る
- `npm run test:fixtures` が通る
- `npm run test:visual` が通る
- `npm audit --audit-level=moderate` が通る
- `git status` に実名CSVやバックアップファイルが混ざっていない
