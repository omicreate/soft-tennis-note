# CSV出力仕様

最終更新: 2026-06-01

## 1. 目的

CSVは、一般利用者向けの見やすい画面ではなく、管理者・開発者・コーチが詳細確認や別ツール分析に使うための出力形式とする。通常画面には出さず、メニュー内の「管理用」に集約する。

## 2. 種類

### 2.1 今の試合CSV

対象:

- 現在開いている1試合
- 1ポイント1行
- 記録が0件の場合はヘッダーのみ出力

ファイル名:

- `soft-tennis-points-YYYYMMDDhhmmss-自チーム-vs-相手ペア.csv`

### 2.2 保存済み試合一括CSV

対象:

- 端末内に保存されている保存済み試合すべて
- フィルター条件に関係なく全件を出力
- 1ポイント1行
- ポイントが0件の保存済み試合も、試合情報を残すために1行出力する

ファイル名:

- `soft-tennis-archive-points-YYYYMMDDhhmmss.csv`

| No | 列名 | 内容 |
| --- | --- | --- |
| 1 | No | 試合内のポイント番号 |
| 2 | 日付 | 試合日 |
| 3 | 時間帯 | 朝、午前、午後、夜など |

| 5 | 終了時刻 | 試合終了時刻 |
| 6 | 天気 | 天気 |
| 7 | 気温 | 気温メモ |
| 8 | 風 | 風の強さ |
| 9 | 風向き | 風上、風下など。現状は基本未記録 |
| 10 | コート種別 | オムニ、クレー、ハード、インドアなど |
| 11 | コート状態 | 乾いている、湿っているなど |
| 12 | 種別 | ダブルス、シングルス |
| 13 | 相手基本布陣 | 雁行陣、W前衛、W後衛など |
| 14 | 区分 | 練習試合、大会など |
| 15 | 大会名 | 大会名または未記録 |
| 16 | 開催地／会場 | 会場名 |
| 17 | コート | 第1コートなど |
| 18 | 試合形式 | 5ゲーム、7ゲーム、9ゲーム、ファイナルのみ |
| 19 | 得点側 | 得点した側 |
| 20 | サービスサイド | そのポイントのサービス側 |
| 21 | サーブ選手 | サーブした選手 |
| 22 | レシーブ選手 | レシーブした選手 |

## 4. 保存済み試合一括CSVの追加列

仕様バージョン: `archive-csv-v1`

通常CSV列の前に、以下の4列を追加する。

| No | 列名 | 内容 |
| --- | --- | --- |
| 1 | 試合No | 一括CSV内の試合番号 |
| 2 | 保存ID | 端末内保存データのID |
| 3 | 保存日時 | 保存済み試合として保存した日時 |
| 4 | 保存タイトル | 保存済み試合画面に表示しているタイトル |

## 5. セキュリティ

CSVセルは、表計算ソフトで数式として解釈される可能性がある文字から始まる場合、先頭に `'` を付ける。

対象:

- `=`
- `+`
- `-`
- `@`
- タブ
- 改行開始

目的:

- CSVインジェクション対策
- 共有先で意図しない数式実行を避ける

## 6. 個人情報の注意

CSVには入力したチーム名、選手名、大会名、会場名が含まれる。

共有する前に確認すること:

- 本名が入っていないか
- 学校名や会場名を共有してよいか
- SNSや外部サービスに送ってよい内容か

開発用fixtureにする場合:

- 元CSVはGitに入れない
- 匿名化済みCSVのみGit管理する
- 大会名、会場名、選手名は検証用名称に置換する
