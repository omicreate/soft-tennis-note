# 技術レビュー・改善バックログ

最終更新: 2026-05-29  
対象バージョン: v145

個人開発者として、現状を忖度なしで見た改善メモ。  
今すぐ全部やるものではなく、テスト運用の反応を見ながら優先度を調整する。

## 対応済み

### P1 `app.js` の分割準備

対応:

- `app-config.js` を追加し、バージョン、保存キー、分析コメント設定、初期状態を分離
- `app-analysis.js` を追加し、分析コメント生成と得点タイプ判定を分離
- `app-storage.js` を追加し、保存済み試合の読み書きと容量表示を分離
- `app-rules.js` を追加し、スコア進行、ゲーム取得、ファイナルゲーム、サーバー交替判定を分離
- `app.js` は `SOFT_TENNIS_CONFIG` を読み込んで動く構成に変更
- Service Workerと静的チェックも `app-config.js`、`app-analysis.js`、`app-storage.js`、`app-rules.js` の読み込みを確認するよう更新

理由:

- 今後 `score`、`analysis`、`storage`、`summary`、`ui` へ段階的に分けるため
- いきなり大分割せず、まず副作用が少ない設定領域から切り出すため

### P2 試合データ保存・読込

対応:

- 現在の試合と保存済み試合を試合データとして保存できるようにした
- 保存した試合データから復元できるようにした
- 別形式のファイルは復元しない
- 利用者向け画面では `JSON` 表記を出さない

理由:

- 端末変更、ブラウザデータ削除、テストユーザーの記録保全に備えるため

### P1 保存データの正規化強化

対応:

- `localStorage` の保存データが一部欠けていても、既定値へフォールバックするよう改善
- `teams`, `players`, `matchInfo`, `games`, `gamePoints`, `points`, `analysisMemos` を正規化

理由:

- テスト運用中にバージョンアップを重ねるため、古い保存データや中途半端な保存データを読めることが重要

### P2 CSVファイル名改善

対応:

- CSVファイル名に年月日・時分秒・チーム名を含める

理由:

- 同じ日に複数回出力した時の重複確認を減らす
- 後から見た時に、どの試合データか分かりやすくする

### P2 サマリー共有キャンセル時の挙動改善

対応:

- 共有画面でキャンセルしただけの場合は、画像保存へ自動で切り替えない
- ブラウザ非対応や共有失敗時のみ保存へ切り替える

理由:

- ユーザーがキャンセルしただけなのに、別操作が始まると混乱するため

### P3 保存済み試合の管理強化

対応:

- 保存済み試合の検索
- 保存済み試合の件数表示
- 保存済み試合の削除
- 保存済み試合の並び替え
- 保存件数と容量の目安表示
- 日付、種目、終了/途中での絞り込み
- 勝敗、大会名での絞り込み

理由:

- テスト運用で試合数が増えた時、同じ日付や同じ相手の記録を探しやすくするため

### P1 実機確認チェックリスト

対応:

- `docs/device-test-checklist.md` を追加
- iPhone Safari、iPhone Chrome、Android Chrome、Google標準ブラウザの確認観点を整理
- 記録、分析、履歴、保存済み試合、サマリー画像、共有、オフラインを確認項目化

理由:

- テストユーザーに公開している段階では、自動テストより実機固有の問題を早く見つける価値が高いため

## 未対応・今後対応候補

### P1 `app.js` の本格分割

現状:

- 設定系は `app-config.js` に分離済み
- 分析コメント生成と得点タイプ判定は `app-analysis.js` に分離済み
- 保存済み試合の読み書きと容量表示は `app-storage.js` に分離済み
- スコア進行とファイナルゲーム判定は `app-rules.js` に分離済み
- サマリーとUI処理はまだ `app.js` に集まっている

リスク:

- 今後の修正で副作用が出やすい
- ピックルボール、テニス、団体戦へ横展開しにくい
- 分析ロジックだけをテストしづらい

対応案:

- `score`、`analysis`、`storage`、`summary`、`ui` の単位で分ける
- ただし現在は静的HTML構成のため、分割時は読み込み方式も含めて慎重に行う

### P1 分析ルールの設定化

一部対応済み:

- 分析コメントの主要なしきい値と表示件数を `ANALYSIS_COMMENT_RULES` に集約
- 分析コメント文言を `ANALYSIS_COMMENT_MESSAGES` に集約

残課題:

- 得点パターン、ミス分類も設定データ化する
- 競技ごとの設定を切り替えられる形にする

### P2 UI自動テスト

対応済み:

- Playwrightを導入
- iPhone SE、iPhone 15、Pixel 8相当の画面幅で主要画面を確認
- 横方向のはみ出しを検査

対応済み:

- サマリー画像本文がフッター領域に重ならないことを単体テストで確認

残課題:

- 実画像のピクセル解析による文字被り検出
- Safari、実機Chromeでの確認記録

### P2 サマリー画像の用途分離

対応済み。

- SNS共有用の短い画像を追加
- 詳細保存用の情報多め画像を追加
- サマリー画像ダイアログで用途を切り替え可能にした

残課題:

- 実際の共有先での見え方はテストユーザーの端末で確認する

### P3 保存済み試合の管理拡張

残課題:

- 対戦相手別など、さらに細かい条件での絞り込み
- 相手名、試合結果など、より細かい条件での並び替え

### P3 利用規約・プライバシー文書の強化

現状:

- `TERMS.md` はあるが、正式サービスや有料化には不足

対応案:

- プライバシーポリシー
- 問い合わせ先
- データ削除方法
- AI機能利用時の外部送信説明
